## 📌 决策流程总结

### 1. 多头入场检查清单
```
□ 价格在支撑位附近（±1%）
□ 支撑位强度 ≥ 70
□ 斐波那契回撤位支持（38.2%-61.8%）
□ RSI < 70（未超买）
□ 布林带未处于上轨外
□ 成交量正常或放大
□ 风险回报比 ≥ 1:3
```

### 2. 空头入场检查清单
```
□ 价格在压力位附近（±1%）
□ 压力位强度 ≥ 70
□ RSI > 60（偏热）
□ 布林带上轨附近或上轨外
□ 出现顶部形态（双顶、头肩顶等）
□ 成交量萎缩（上涨乏力）
□ 风险回报比 ≥ 1:3
```

### 3. 突破交易检查清单
```
□ 突破关键压力位/支撑位
□ 突破成交量 > 平均值的1.5倍
□ 有回踩确认
□ 布林带宽度扩张
□ 趋势一致性（多时间周期确认）
□ 快速止损保护
```

## 🎯 实战技巧

### 技巧1：多时间周期确认
```
4小时：确定大趋势
1小时：寻找入场点
15分钟：精确进场时机
```

### 技巧2：等待回撤入场
```
不要追高/杀跌
等待价格回撤到关键位
使用斐波那契+支撑位确认
```

### 技巧3：成交量确认
```
上涨需要成交量配合
下跌不一定需要大量
突破必须有成交量确认
```

### 技巧4：动态调整止损
```
盈利后移动止损到关键支撑位
保护利润，让盈利奔跑
避免在关键位前止损（容易被扫）
```

### 技巧5：分批建仓
```
第一仓：在斐波那契38.2%
第二仓：在斐波那契50%
第三仓：在斐波那契61.8%
降低平均成本，提高胜率
```

## ⚠️ 常见错误

### 错误1：忽视成交量
```
❌ 只看价格突破
✅ 必须成交量确认
```

### 错误2：过度交易
```
❌ 每个信号都做
✅ 只做高胜率信号（confidence ≥ 75）
```

### 错误3：不止损
```
❌ 抗单等反弹
✅ 严格执行止损
```

### 错误4：重仓赌博
```
❌ 单笔仓位 > 50%资金
✅ 单笔仓位 ≤ 20%资金
```

### 错误5：逆势交易
```
❌ 在强趋势中抄底摸顶
✅ 顺势而为，趋势是朋友
```
